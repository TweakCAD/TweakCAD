# FreeCAD fixtures

The `.FCStd` files are written by `generate.py` with FreeCAD (see its
docstring); each is a small document FreeCAD solved and saved.

`nozzle-0.19.Document.xml` is the `Document.xml` of `PUISS_Buse.FCStd` from
[TomGosnik/FairEmbo-Project](https://github.com/TomGosnik/FairEmbo-Project),
released under CC0-1.0. It stands for a file saved by an older FreeCAD.
